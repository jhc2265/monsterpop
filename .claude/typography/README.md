# 타이포그래피 검사

`src/index.css` 의 타이포그래피가 토큰 시스템을 벗어나지 않는지 확인한다.

## 왜 두 개인가

CSS 를 만지다 낸 회귀는 두 종류였다.

| 유형 | 예 | 잡는 검사 |
|---|---|---|
| px 값이 다시 스며듦 | `font-size: 14px` | **정적** |
| 선언을 지우고 대체를 안 넣어 **상속으로 떨어짐** | `.community-intro` 가 16px, 레벨업 모달 전체 | **동적** |

정적 검사는 CSS 텍스트만 보므로 "선언이 없는" 요소를 볼 수 없다.
실제로 낸 회귀는 대부분 두 번째 유형이었다. 두 검사를 모두 돌려야 한다.

---

## 1. 정적 검사 (빠름 · 브라우저 불필요)

```bash
node .claude/typography/audit-static.mjs
```

`font-size` / `font-weight` / `letter-spacing` / `line-height` 의 모든 선언이
토큰(`var(--fs-*)` 등)인지 검사한다. 실패 시 종료 코드 1.

## 2. 동적 검사 (실제 렌더 결과)

```bash
npm run build
node .claude/typography/prepare.mjs
npx vite preview --port 4173
```

브라우저에서 `http://localhost:4173/__audit.html` 을 열고,
DevTools 콘솔에 `audit.js` 내용을 통째로 붙여넣는다.

> `dist/` 를 거치는 이유: vite dev 서버는 `.claude` 같은 점(.) 디렉터리를 서빙하지 않는다.
> `dist/` 는 `.gitignore` 에 있고 `vite build` 가 매번 비우므로 저장소가 더러워지지 않는다.

검사 항목:

1. **px 하드코딩** — 이기는 규칙의 값이 토큰/rem 이 아닌 경우
2. **11px 미만** — 스케일 하한 위반
3. **font-weight ≥900** — `<strong>` 의 UA 기본값 `bolder` 가 굵은 부모 안에서 900 으로 계산되는 함정 포함
4. **대비 AA** — 반투명 배경을 합성해 계산. `color: transparent`(그라디언트 텍스트)는 제외
5. **상속 스케일 이탈** — 규칙이 없으면서 부모 크기와도 다른 요소
6. **텍스트 잘림** — 의도된 말줄임과 배경 블리드는 제외
7. **가로 오버플로**

## 스케일

| 토큰 | px | 용도 |
|---|---|---|
| `--fs-display` | 48 | 점수 · 카운트다운 |
| `--fs-h1` | 24 | 페이지 제목 |
| `--fs-h2` | 20 | 카드 제목 |
| `--fs-h3` | 17 | 소제목 · 강조 숫자 |
| `--fs-body` | 15 | 본문 |
| `--fs-body-sm` | 13 | 보조 본문 |
| `--fs-label` | 12 | 라벨 · 메타 |
| `--fs-caption` | 11 | 최소 |

굵기는 `--fw-regular(400)` / `medium(500)` / `semibold(600)` / `bold(700)` / `black(800)`.
**900 과 1000 은 쓰지 않는다.**

### 스케일 밖이 정당한 경우

rem 리터럴로 쓰고 주석을 단다. 정적 검사가 통과시키되 목록으로 보여준다.

- **글리프** — `›` `→` `@` `×` `♥` 등. 텍스트가 아니라 아이콘이다.
- **디스플레이 타입** — 워드마크 32px, 카운트다운 92px, 점수 clamp
- **폼 입력 16px** — iOS Safari 는 16px 미만 입력에 포커스하면 페이지를 확대한다

## 하네스 유지보수

`audit-harness.html` 은 10개 화면의 마크업 사본이다.
**JSX 를 바꿔 새 텍스트 요소가 생기면 여기에도 추가해야 검사에 걸린다.**

- 화면 구분은 `data-s="화면이름"` 으로 단다
- 아이콘 자리는 `<svg>` 로 둔다. 텍스트를 넣으면 크기 오탐이 난다
- 모달·빈 상태처럼 조건부로 뜨는 것은 `left:-9999px` 블록에 모아둔다
